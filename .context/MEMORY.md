# Memória Arquitetural e Visão do Projeto

## Sobre o Projeto
- **Nome:** Vitrine Web
- **Domínio:** `https://agenciavitrineweb.com.br`
- **Propósito:** Software house e agência digital especializada em sistemas web sob medida, landing pages de alta conversão e ERPs corporativos.
- **Fundadores:** Daniel Barrionuevo & Natanael Balbo.

## Stack Tecnológica
- **Frontend:** React 19, Vite 8, Tailwind CSS v4, Lucide React, Three.js / React Three Fiber, GSAP, Lenis.
- **Deploy:** Vercel (`main` branch automatizado via Git).
- **SEO & Search Console:** Schema.org JSON-LD (Organization, ProfessionalService, WebSite, Service, FAQPage), Sitemap XML com imagens, robots.txt, Google Search Console API com Service Account.
- **Rotas Públicas:**
  - `/` (Home)
  - `/criacao-de-landing-page`
  - `/desenvolvimento-de-sistemas-web`
  - `/sistema-erp-sob-medida`
