# Protocolo Universal de Agentes (AGENTS.md)

Este documento rege a atuação de agentes de inteligência artificial neste repositório.

## Diretrizes Gerais
1. **Respeito ao UPM:** Sempre verificar e atualizar `.context/STATUS.md` e `.context/DECISIONS.md`.
2. **Segurança:** Nunca comitar chaves de API, credenciais ou dados sensíveis (`google-credentials.json`, `.env`).
3. **Qualidade Técnica:** Priorizar boas práticas de SEO técnico, Core Web Vitals, acessibilidade e design responsivo.
4. **Verificação em Tempo Real:** Sempre validar dados com a API do Google Search Console ou inspeção direta.
